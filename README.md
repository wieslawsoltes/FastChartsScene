# FastChartsScene

Independent, reusable scientific charting libraries and an Uno Platform desktop/WebAssembly explorer.

## Status

Implementation in progress. LightningChart .NET public documentation is a behavioral reference, not a source-code dependency. This project is not affiliated with LightningChart and does not redistribute its proprietary code, binaries, artwork, or branding. Full API, visual, performance, and functional parity has not been established.

The intended package boundaries are numerical/data core, chart scene models, rendering, interaction, reusable Uno controls, and the sample explorer. Verified functionality and outstanding compatibility work will be recorded in the repository documentation.
